# Columnist

x.com のリスト・検索・タイムラインを縦カラムで横に並べ、自動更新しながら眺めるための個人用デスクトップアプリです。

公式Web画面をそのまま複数並べて表示するだけの専用ブラウザで、API は使いません。

## 免責

- 本アプリは公式Web画面を表示するだけのブラウザです。投稿データの収集・保存・加工や、クリック・入力・投稿などの自動操作は行いません。
- X の利用規約は、各自の責任で遵守してください。

## ログイン

初回起動時にログイン画面が表示されます。**ユーザー名とパスワード(必要に応じて2段階認証)でログインしてください。**

- Google などの外部アカウントでのログインは、組み込みブラウザではブロックされる場合があります。
- パスワードの保存・自動入力は行いません。ログイン状態はアプリ内のセッションに保持され、次回以降はログイン不要です。

## 使い方

ツールバーの入力欄に次のいずれかを入力して「追加」を押すと、カラムが右端に追加されます。

| 入力                                      | 表示されるもの               |
| ----------------------------------------- | ---------------------------- |
| 数字のみ(例 `1234567890`)                 | そのIDのリスト               |
| `https://x.com/i/lists/...`               | リスト                       |
| `@ユーザー名`(例 `@sudabon`)              | そのユーザーのプロフィール   |
| `search:キーワード`(例 `search:electron`) | キーワードの検索結果(最新順) |
| `home`                                    | ホームのタイムライン         |
| その他の `https://x.com/...` のURL        | そのページ                   |

### リストから選ぶ

リストのIDやURLが分からないときは、ツールバーの「リストから選ぶ」を使います。

1. 「リストから選ぶ」を押すと、ツールバーの下に x.com の画面が開きます(ログイン状態はカラムと共通です)。
2. x.com のメニューから自分のリスト一覧を開き、追加したいリストを開きます。
3. リストのページを表示している間だけ「このリストを追加」が押せます。押すとそのリストがカラムとして右端に追加され、画面が閉じます。追加せずに戻るときは「キャンセル」を押します。

- アプリは開いている画面の URL だけを見て追加し、画面の内容は読み取りません。そのため、追加されたカラムのタイトルはリスト名ではなく「リスト <ID>」になります。名前はタイトルのダブルクリックで変更できます。
- リストのメンバー一覧などの下位ページを表示している間は追加できません。
- 開いている間もカラムの自動更新は続きます。

- 各カラムは一定間隔(既定 120 秒)で自動的に再読み込みされます。スクロールして読んでいる途中・操作中・投稿の詳細を表示中・動画の再生中は再読み込みしません。
- 詳細画面を開いたときは、カラムヘッダの「←」で戻る、「⌂」で元のページに戻れます。
- ウィンドウに入りきらないカラムは、最下部の横スクロールバーで表示できます。
- カラムヘッダをドラッグ&ドロップすると、カラムの順序を変更できます。
- カラムヘッダのタイトルをダブルクリックすると名前を変更できます(Enter で確定、Escape で取消)。
- カラムヘッダの「⏸」で自動更新を一時停止、「▶」で再開します。一時停止中も「↻」で手動更新できます。ツールバーから全カラムをまとめて一時停止・再開することもできます。
- カラムヘッダの「⚙」でそのカラムの幅(300〜640px)・更新間隔(60〜3600秒)・ズーム(0.5〜1.5)を変更できます。ツールバーの「デフォルト設定」で、新しく追加するカラムの既定値を変更できます(既存のカラムは変わりません)。
- シェル(ツールバー・ヘッダ・スクロールバー)の配色は OS のライト/ダーク設定に追従します。カラム内の表示は x.com 側の設定に従います。
- 設定は `~/Library/Application Support/columnist/config.json` に保存されます。

### キーボードショートカット

フォーカスがツールバーとカラムのどちらにあっても使えます。

| キー                        | 操作                                                                  |
| --------------------------- | --------------------------------------------------------------------- |
| `Cmd+T`                     | カラム追加の入力欄へ移動                                              |
| `Cmd+Shift+R`               | 全カラムを再読み込み                                                  |
| `Cmd+P`                     | 全カラムの一時停止/再開を切り替え(停止していないカラムがあれば全停止) |
| `Cmd+1`〜`Cmd+9`            | 左から N 番目のカラムへ移動(画面外なら見える位置まで横スクロール)     |
| `Cmd+=` / `Cmd+-` / `Cmd+0` | フォーカス中カラムを拡大 / 縮小 / 等倍(0.5〜1.5、保存される)          |
| `Cmd+Option+I`              | フォーカス中カラムの開発者ツールを開く                                |

これらのキーはアプリが使うため、カラム内(x.com 側)の同じキーのショートカットは使えません。

## 開発

```bash
npm install
npm run dev             # 開発モードで起動
npm run lint            # ESLint
npm run typecheck       # 型チェック
npm test                # ユニットテスト(Vitest)
npm run test:e2e        # E2E テスト(Playwright for Electron。ローカルの fixture を表示する)
npm run check:guardrails # 禁止事項の機械的な検査
```

E2E テストは実サイトにはアクセスしません。テストビルド(`npm run build:test`)でのみ、環境変数 `COLUMNIST_TEST_ORIGIN` で表示先をローカルの fixture サーバに切り替えます。

## ビルド

```bash
npm run build:mac   # macOS 向けにパッケージング(dist/ に出力)
npm run build:unpack # パッケージングせずにアプリを生成
```
