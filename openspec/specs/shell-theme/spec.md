# shell-theme Specification

## Purpose
シェルUI(ツールバー・カラムヘッダ・ダイアログ・スクロールバー)の外観を OS のライト/ダーク設定に合わせ、x.com の表示と並べても違和感がないようにする。

## Requirements

### Requirement: OS のカラースキームへの追従
シェルUIは OS のライト/ダーク設定に追従して配色を切り替えなければならない(MUST)。OS の設定が実行中に変わった場合も、再起動なしで反映しなければならない(MUST)。

#### Scenario: ダークモードで起動
- **WHEN** OS がダークモードの状態でアプリを起動する
- **THEN** ツールバー・カラムヘッダ・ダイアログがダーク配色で表示される

#### Scenario: 実行中の切り替え
- **WHEN** アプリ実行中に OS の設定をライトからダークへ切り替える
- **THEN** シェルUIが再起動なしでダーク配色に切り替わる

### Requirement: x.com の表示に介入しない
テーマ切り替えはシェルUIのみに適用し、カラムビュー(x.com)へ配色のための CSS 注入やスクリプト実行を行ってはならない(MUST NOT)。

#### Scenario: カラムの配色は x.com 側に任せる
- **WHEN** OS をダークモードに切り替える
- **THEN** カラムビューに対してアプリから追加の CSS やスクリプトは適用されない
