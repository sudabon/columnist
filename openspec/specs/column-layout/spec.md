# column-layout Specification

## Purpose
複数のカラムを固定幅で横に並べ、ウィンドウ幅を超える場合は横スクロールで全カラムを閲覧できるようにする。x.com の表示は最小限の見た目調整のみ行う。

## Requirements

### Requirement: ウィンドウレイアウト
ウィンドウは上部に高さ 40px のツールバー、その下に各カラムの高さ 32px のヘッダ帯、その下にカラム本体、最下部に横スクロールバーを配置しなければならない(MUST)。各カラムのヘッダとカラム本体は同じ横位置・幅で揃わなければならない(MUST)。

#### Scenario: ヘッダとカラムが揃う
- **WHEN** 幅の異なる複数のカラムが表示されている
- **THEN** 各カラムヘッダの左端と幅は、その下のカラム本体と一致する

#### Scenario: ウィンドウのリサイズに追従
- **WHEN** ユーザーがウィンドウの高さを変更する
- **THEN** カラム本体の高さがウィンドウに合わせて再計算される

### Requirement: 固定幅カラムの横並び
カラムは設定された幅(デフォルト 380px)で左から順に隙間なく横に並べなければならない(MUST)。

#### Scenario: デフォルト幅で並ぶ
- **WHEN** デフォルト設定のカラムが3本ある
- **THEN** 各カラムは幅 380px で x=0, 380, 760 の位置に表示される

### Requirement: 横スクロール
カラムの合計幅がウィンドウ幅を超える場合、横スクロールバーを表示し、スクロール位置に応じて全カラムの表示位置を移動しなければならない(MUST)。ウィンドウ外に完全に出たカラムは非表示にしなければならない(MUST)が、その自動更新タイマーは継続しなければならない(MUST)。

#### Scenario: ウィンドウ幅を超えるカラム
- **WHEN** ウィンドウ幅より合計幅が大きくなるまでカラムを追加する
- **THEN** 横スクロールバーが表示され、スクロールすることで全カラムを閲覧できる

#### Scenario: 画面外カラムの非表示
- **WHEN** 横スクロールによりあるカラムが完全に画面外へ出る
- **THEN** そのカラムは非表示になり、画面内へ戻ると再び表示される

#### Scenario: 合計幅がウィンドウ内に収まる
- **WHEN** カラムの合計幅がウィンドウ幅以下である
- **THEN** 横スクロールは発生せず、スクロール位置は 0 に保たれる

### Requirement: 見た目調整 CSS の注入
システムはカラムビューのページ読み込み完了(`dom-ready`)のたびに見た目調整用 CSS を注入しなければならない(MUST)。CSS が効かなくなった場合でも、表示が崩れるだけでアプリの機能は停止してはならない(MUST NOT)。

#### Scenario: 遷移後も CSS が維持される
- **WHEN** カラム内でページ遷移が起き、新しいページが読み込まれる
- **THEN** 見た目調整 CSS が再度適用される
