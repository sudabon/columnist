# Spec Delta

## Purpose

Columnist を「x.com の公式Web画面を並べて表示するだけの専用ブラウザ」に留めるため、データ取得・自動操作・商標使用などの禁止事項と、カラムビューで許可される操作の範囲を定める。

## ADDED Requirements

### Requirement: X API および非公式内部APIを使用しない
システムは X API(`api.x.com`)を呼び出してはならない(MUST NOT)。また x.com の非公式内部API(GraphQL 等)を直接呼び出したり、カラムビューの通信を傍受・改変・リプレイしてはならない(MUST NOT)。

#### Scenario: コードベースに API 呼び出しが存在しない
- **WHEN** ソースコードを `api.x.com`、`graphql`、`webRequest` の改変系ハンドラで検索する
- **THEN** カラムビューの通信を取得・改変する呼び出しは見つからない

### Requirement: 投稿内容・ユーザー情報を読み取らない
システムはカラムビューの DOM から投稿内容・ユーザー情報を読み取ってはならず(MUST NOT)、それらを保存・送信・集計・通知に使用してはならない(MUST NOT)。新着通知・キーワード検知など表示内容に依存する機能を提供してはならない(MUST NOT)。

#### Scenario: 新着投稿の通知を出さない
- **WHEN** カラムが再読み込みされ新しい投稿が表示される
- **THEN** システムはデスクトップ通知・バッジ・音などを一切発しない

### Requirement: 自動操作を行わない
システムはカラムビュー内で自動クリック・自動入力・自動投稿・自動いいね・自動フォローを行ってはならない(MUST NOT)。「新しいポストを表示」ボタンの自動クリックも行ってはならない(MUST NOT)。ログイン時の資格情報の保存・自動入力も行ってはならない(MUST NOT)。

#### Scenario: 新着ボタンを押さない
- **WHEN** x.com 上に新着投稿の表示ボタンが現れる
- **THEN** システムはそれをクリックせず、更新は再読み込みのみで行う

### Requirement: カラムビューで実行できるスクリプトの限定
カラムビューで実行する JavaScript は、スクロール位置の取得(`window.scrollY` を返す)、先頭へのスクロール(`window.scrollTo(0, 0)`)、操作中判定(`mousemove`/`wheel`/`keydown`/`pointerdown` の最終発生時刻のみを `window.__columnistLastInput` に記録)の3種に限られなければならない(MUST)。これらは単一の定義箇所に集約され、それ以外の場所からカラムビューへスクリプトを実行してはならない(MUST NOT)。

#### Scenario: 許可外のスクリプト実行が存在しない
- **WHEN** コードベースを `executeJavaScript` で検索する
- **THEN** 呼び出し箇所は許可スクリプトの定義箇所を経由するもののみである

#### Scenario: 操作中判定スクリプトは時刻以外を記録しない
- **WHEN** ユーザーがカラム上でマウスを動かす
- **THEN** 記録されるのは最終操作時刻の数値のみで、座標・キー・対象要素は記録されない

### Requirement: 注入 CSS は見た目調整に限る
カラムビューへ注入する CSS は、要素の非表示・余白・幅の調整に限られなければならない(MUST)。CSS は単一ファイルに集約し、その先頭に最終確認日を記載しなければならない(MUST)。

#### Scenario: CSS ファイルに最終確認日がある
- **WHEN** 注入 CSS ファイルを開く
- **THEN** 先頭コメントに最終確認日が記載されている

### Requirement: 商標を使用しない
アプリ名・アイコン・UI 文言に X の商標(Xロゴ、"X"、"Twitter"、"Tweet"、鳥のロゴ)を使用してはならない(MUST NOT)。

#### Scenario: UI 文言に商標が含まれない
- **WHEN** シェル UI の文言・アプリ名・メニュー項目を確認する
- **THEN** "Twitter"、"Tweet"、単独の "X" 表記、X/鳥のロゴは含まれない

### Requirement: 配布・外部送信機能を持たない
システムはアカウント共有、サーバ連携、テレメトリ送信など配布・SaaS 化を前提とした機能を持ってはならない(MUST NOT)。

#### Scenario: x.com 以外へ通信しない
- **WHEN** アプリを通常利用する
- **THEN** アプリ自身が x.com とその表示に必要なリソース以外の外部サーバへ通信することはない

### Requirement: README に免責を記載する
README は、本アプリが X Corp. と無関係で承認・提携を受けていないこと、公式Web画面を表示するだけでデータ収集・自動操作を行わないこと、X の利用規約は各自の責任で遵守することを記載しなければならない(MUST)。

#### Scenario: 免責の記載
- **WHEN** README を確認する
- **THEN** 上記3点の免責が記載されている
