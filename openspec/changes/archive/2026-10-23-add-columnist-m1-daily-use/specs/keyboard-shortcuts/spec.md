# Spec Delta

## Purpose

マウスに手を伸ばさずに、カラムの追加・更新・移動・一時停止・ズーム・開発者ツールを操作できるようにする。

## ADDED Requirements

### Requirement: アプリ操作のショートカット
システムは次のショートカットを提供しなければならない(MUST)。`Cmd+T` でカラム追加ダイアログを開く。`Cmd+Shift+R` で全カラムを再読み込みする。`Cmd+P` で全カラムの一時停止/再開を切り替える(1つでも一時停止していないカラムがあれば全停止、全カラムが一時停止中なら全再開)。ショートカットはフォーカスがシェルとカラムのどちらにあっても動作しなければならない(MUST)。

#### Scenario: カラム追加
- **WHEN** ユーザーが `Cmd+T` を押す
- **THEN** カラム追加ダイアログが開く

#### Scenario: 全カラム更新
- **WHEN** カラムにフォーカスがある状態でユーザーが `Cmd+Shift+R` を押す
- **THEN** すべてのカラムが再読み込みされる

#### Scenario: 全カラム一時停止の切り替え
- **WHEN** 一時停止していないカラムがある状態で `Cmd+P` を押し、続けてもう一度 `Cmd+P` を押す
- **THEN** 1回目で全カラムが一時停止し、2回目で全カラムが再開する

### Requirement: カラムへのフォーカス移動
`Cmd+1`〜`Cmd+9` で左から N 番目のカラムにフォーカスしなければならない(MUST)。対象カラムが画面外にある場合は、そのカラム全体が見える位置まで横スクロールしなければならない(MUST)。該当するカラムが存在しない場合は何もしてはならない(MUST NOT)。

#### Scenario: 画面外のカラムへ移動
- **WHEN** 7番目のカラムが画面外にある状態で `Cmd+7` を押す
- **THEN** 7番目のカラムが見える位置まで横スクロールし、そのカラムにキーボードフォーカスが移る

#### Scenario: 存在しないカラム
- **WHEN** カラムが3本の状態で `Cmd+5` を押す
- **THEN** スクロール位置もフォーカスも変化しない

### Requirement: フォーカス中カラムの DevTools とズーム
`Cmd+Option+I` でフォーカス中カラムの開発者ツールを開かなければならない(MUST)。`Cmd+=` / `Cmd+-` / `Cmd+0` でフォーカス中カラムのズームを拡大・縮小・1.0 に戻さなければならず(MUST)、ズームは 0.5〜1.5 の範囲に制限され、保存されなければならない(MUST)。カラムにフォーカスがない場合、これらは何もしてはならない(MUST NOT)。

#### Scenario: ズームの拡大と保存
- **WHEN** フォーカス中カラムのズームが 1.0 の状態で `Cmd+=` を押し、再起動する
- **THEN** そのカラムのみ拡大表示され、再起動後も同じズームで表示される

#### Scenario: ズームの上限
- **WHEN** ズームが 1.5 のカラムで `Cmd+=` を押す
- **THEN** ズームは 1.5 のまま変化しない

#### Scenario: フォーカス中カラムの DevTools
- **WHEN** 2番目のカラムにフォーカスがある状態で `Cmd+Option+I` を押す
- **THEN** 2番目のカラムの開発者ツールが開く
